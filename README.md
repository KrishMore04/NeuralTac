# NeuralTac — AI Algorithm Lab

An interactive web-based Artificial Intelligence project that demonstrates three important AI algorithms: **Minimax with Alpha-Beta Pruning, A* Search, and Hill Climbing**.

🌐 Live Demo: https://neuraltac.onrender.com  
💻 GitHub Repository: https://github.com/KrishMore04/NeuralTac

## Project Overview

NeuralTac is an interactive AI learning platform designed to visualize how search and optimization algorithms work. Users can play against an AI opponent, explore shortest-path search on a grid, and observe an optimization algorithm searching for a better solution.

## Algorithms Implemented

### 1. Minimax with Alpha-Beta Pruning
- Implements an AI opponent for Tic-Tac-Toe.
- Minimax evaluates possible game states to select a strategic move.
- Alpha-Beta Pruning reduces unnecessary search by skipping branches that cannot affect the final decision.
- Includes difficulty settings.

### 2. A* Search Algorithm
- Finds a path between a starting point and a goal on a grid.
- Uses a heuristic to guide the search toward the goal.
- Supports obstacles and randomized maze layouts.
- Displays the resulting path length and number of explored nodes.

### 3. Hill Climbing Algorithm
- Demonstrates local-search optimization on an objective function.
- Starts from an initial position and searches neighboring positions for improvements.
- Visualizes the objective function and final position.
- Displays the final objective value and number of iterations.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

No backend server or package installation is required.
