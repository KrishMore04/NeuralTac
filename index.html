PROJECT OVERVIEW

How the algorithms work

Minimax + Alpha-Beta

Used for two-player games. Minimax evaluates possible outcomes while Alpha-Beta Pruning skips branches that cannot improve the decision.

A* Search

Ranks paths using f(n) = g(n) + h(n), combining the cost already traveled with a heuristic estimate to the goal.

Hill Climbing

Repeatedly moves to a better neighboring state until no neighbor improves the objective value. It can stop at a local maximum.
